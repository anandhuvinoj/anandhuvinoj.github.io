# ANANDHU VINOJ — Portfolio

A responsive static portfolio built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish free with GitHub Pages
1. Create a public repository named `anandhuvinoj.github.io` in your GitHub account.
2. Upload the contents of this folder (not the parent folder).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site will be published at https://anandhuvinoj.github.io.
